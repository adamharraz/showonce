# Homepage interface previews

These images show ShowOnce's own interface, captured locally with Playwright.
`capture.png` and `coach.png` show idle setup controls from an isolated test server.
`lesson.png` uses illustrative spreadsheet lesson content substituted in the browser's response only; it is labelled as an example on the homepage. It is not evidence of an actual user lesson or AI output.

No personal information, API keys, camera footage, or real AI sessions were used.
